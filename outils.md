# UTILISATION OBLIGATOIRE DES OUTILS CLAUDE CODE

Avant tout développement, vérifie et installe les quatre outils suivants.

Ne les confonds pas : ils ont chacun un rôle différent et complémentaire.

### 1. PONYTAIL
Repository : https://github.com/DietrichGebert/ponytail

Utilise Ponytail pour :
- Éviter le surdéveloppement.
- Privilégier les solutions simples.
- Réutiliser les dépendances et composants existants.
- Éviter les abstractions inutiles.
- Maintenir une architecture propre.
- Limiter le code superflu.

### 2. GRAPHIFY
Repository : https://github.com/Graphify-Labs/graphify

Utilise Graphify pour :
- Analyser l'ensemble du projet.
- Générer une cartographie du code.
- Comprendre les relations entre composants.
- Identifier les dépendances.
- Comprendre l'architecture.
- Faciliter les modifications sans casser l'existant.

### 3. AGENT SKILLS
Repository : https://github.com/addyosmani/agent-skills

Utilise Agent Skills pour :
- Identifier les compétences pertinentes pour le projet.
- Structurer le développement.
- Organiser les différentes phases.
- Appliquer les bonnes pratiques.
- Effectuer des vérifications systématiques.
- Exploiter les compétences spécialisées disponibles.

### 4. UNSLOP
Repository : https://github.com/heydamir/unslop

Utilise UNSLOP pour :
- Auditer l'interface.
- Définir une direction artistique.
- Éliminer les designs génériques.
- Améliorer la typographie.
- Travailler les espacements.
- Améliorer la composition visuelle.
- Perfectionner les animations et interactions.
- Effectuer une dernière passe de finition.

### Règles d'utilisation

1. Consulte la documentation officielle de chaque outil.
2. Vérifie leur installation réelle.
3. Installe-les selon leurs instructions officielles respectives.
4. Ne réinstalle pas inutilement un outil déjà disponible.
5. Utilise réellement chaque outil pendant le projet.
6. Ne prétends jamais avoir exécuté un outil si ce n'est pas le cas.

Chaque outil doit intervenir au moment approprié.

Ponytail doit guider les décisions de développement, Graphify l'analyse de l'architecture, Agent Skills l'organisation et les compétences du travail, et UNSLOP la qualité visuelle.

À la fin du projet, indique précisément les outils utilisés et les opérations réellement effectuées.
